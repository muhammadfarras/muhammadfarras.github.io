# Pengenalan Singkat Golang
 
Project yang menggunakang *Go* disebut dengan _module_.

!!! quote "Command Initialization Go Module"

    === "Command Prompt"

        ```cmd
            go mod init main
        ```

        Buat sebuah module go dengan nama package _go.mod_.

Sangat disarankan untuk tidak mengubah nilai `go.mod` secara manual tanpa menggunakan perintah `#!cmd go mod get` atau `#!cmd go tidy`.

!!! quote "ch1_intro"

    === "main.go"

        ```go
            package main

            import "fmt"

            func main() {
                fmt.Println("Bismillah")
            }
        ```

Berbeda dengan bahasa pemprogramn yang lain, fungsi `#!go import` pada GoLang meng-import semua library atau package didalamnya.

Jalankah perintah `#!cmd go build` untuk meng-compile file go. Jalankan file `exe` (Jika menggunakan windows). Juga dapat menggunakan opsi `-o` jika compiled file atau lokasi compiled file ingin dikostumisasi.

## go fmt

Tool `go fmt` berguna untuk merapihkan struktur atau format kode sesuai standard, seperti format document pada sebuah IDE atau Text Editor.

!!! quote "Command"

    === "cmd"

        ```cmd
            go fmt ./...

            // Atau

            go fmt main.go // Nama main file
        ```

!!! info
    Sangat disarankan untuk menjalankan perintah tersebut sebelum melakukan operasi kompilasi dan operasi commit perubahan.

## go vet

Tools atau command ini berguna untuk memvalidasi atau mendeteksi adanya bugs atau kode error sebelum membuat aplikasi.
